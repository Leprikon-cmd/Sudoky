# PREVIEW-FONT-02 — миниатюра поля в настройках

Задание владельца от 15 октября 2026. Реализовано, ожидается личная приёмка.

## Границы

Меняется только миниатюра судоку. Компоновка настроек, настоящий игровой
экран, логика кандидатов, сохранения и шрифтовая политика не меняются.
Предпросмотр продолжает использовать GameBoardView и CellView;
независимый renderer заметок не создаётся. Специальные параметры preview
не должны менять прежнее поведение реального поля по умолчанию.

## Выявленные причины

В миниатюре поле шириной 220 pt находится в контейнере 234 pt.
Рамка использует отдельные размеры/коррекцию и смещение (-5,+5),
поэтому её видимые границы не совпадают с сеткой.
Кандидаты: три позиции по cellSize/3 плюс два промежутка по 1 pt
делают внутреннюю сетку на 2 pt больше клетки по каждой оси.
Фиксированные offsets декоративных шрифтов применяются и к миниатюрным
цифрам; нужны ограниченные клеткой метрики, учитывающие реальный глиф.

## Критерии

- Ровная одна рамка по 9×9, без дополнительного декоративного обрамления.
- 81 одинаковая клетка, сохранены более толстые разделители 3×3.
- Заметки на правильных позициях 3×3, центрированы и имеют одинаковый
  масштаб в рамках выбранного шрифта, без обрезания и выхода из клетки.
- Допускается слегка увеличить только миниатюру для читаемости.
- Проверить System, Old Standard TT, Skranji и прочие декоративные шрифты.
- Изолированные данные предпросмотра не связаны с текущей партией.
- Соразмерные программные проверки и успешная компиляция.

Владелец запросил три скриншота System/Old Standard TT/Skranji.
В прежней проверке окружения Simulator.app отсутствовал; получение снимков
не считается выполненным по компиляции или расчётам метрик.
## Результат

Изменены SettingsView.swift, GameBoardView.swift, CellView.swift и
FontManager.swift. Введён ограниченный режим fontPreview с прежним
standard по умолчанию для настоящего поля. Сетка и рендер кандидатов общие.

Миниатюра адаптивна, до 252×252 pt вместо поля 220 pt в контейнере 234 pt.
Убраны preview-only inset и коррекция картинки; декоративный asset не рисуется.
Внешняя рамка strokeBorder 3 pt внутри границ 9×9, разделители 3×3 — 3 pt.
Для кандидатов промежуток 0: девять позиций точно заполняют клетку.
Кегль един для всех кандидатов выбранной гарнитуры, подобран по CoreText.
Preview-смещение учитывает глиф и ограничено ±1,5 pt, без старого общего
смещения декоративного шрифта. Реальная игра сохраняет прежние значения.

Проверены 81 клетка, 9 исходных, 6 введённых и 6 клеток с заметками;
пересечений фикстуры нет, кандидаты в пределах 1–9. Проверка геометрии
при ширине 252/240/216 pt прошла. Проверены System, Old Standard TT,
Skranji и все остальные встроенные гарнитуры. При поле 252 pt позиция
кандидата имеет сторону 9,33 pt; вычисленный кегль System 9,49 pt,
Old Standard TT 9,65 pt, Skranji 8,98 pt. Глифы и смещение по проверенным
метрикам помещаются в позиции. Программные проверки не заменяют UI-приёмку.

Финальная инкрементальная Debug-компиляция успешна. Симулятор не запускался,
три запрошенных скриншота не получены. Остальные настройки, настоящая партия,
логика заметок, шрифтовая политика и сохранения не изменялись.

## Уточнение владельца PREVIEW-FRAME-04

Владелец вручную установил толщину внешнего strokeBorder в 1 pt и
majorLineWidth в `presentation == .fontPreview ? 1 : 1`.
Эти ручные правки не откатывать, в том числе ветку настоящего поля.
Деревянную рамку нужно вернуть: её удаление было неверной интерпретацией
задачи точного позиционирования. Дополнительный программный периметр
не должен дублировать деревянную рамку.

Используется прежний PNG game_board_frame_thin без изменения байтов.
Холст 1224×1224, внутреннее прозрачное отверстие по центральным сечениям
примерно (42,12,1171,1171), центр (627,5;597,5), а не центр холста (612;612).
Слабый шум alpha не использовать как видимые границы. Геометрия preview
должна согласовать внутренний край дерева с сеткой, учесть асимметричные
поля PNG и не обрезать внешнюю часть рамки. Настоящую рамку и метрики
заметок не перерабатывать.

Выполнено в GameBoardView.swift: деревянный ассет снова отображается
в preview, его внутреннее окно масштабируется до размера сетки со
смещением по центру окна, контейнер учитывает полный холст. Дополнительный
strokeBorder убран, чтобы внешний край задавало дерево. Внутренние major-линии
сохранены по 1 pt, включая ручное значение владельца в standard-ветке.
Расчёты совмещения на ширинах 132/184/252/320/480 pt: ошибка 0 pt.
PNG и стандартная геометрия рамки не менялись, метрики заметок сохранены.
Инкрементальная компиляция успешна, симулятор не запускался.
Визуальная приёмка владельцем ожидается.
