# PERF-WARN-01

15 октября 2026. Владелец сообщил о предупреждениях и торможении первого
запуска. Релизный кандидат до исправления и проверки не считать финальным.
Статус — исправлено и скомпилировано, ожидается проверка владельцем
на устройстве. Без симулятора и без публикации.

## Наблюдения владельца

- DifficultyPickerView: Invalid frame dimension на строках 140, 144, 253.
- MusicManager: AVAudioSession Hang Risk при setActive на main thread,
  строки 37, 53, 81.
- FontManager: Publishing changes from within view updates, строка 143.

## Первичный диагноз по исходникам

Геометрия использует деление на canvasSize.height без обработки нулевого
переходного размера; первый разделитель содержит 20 / height. Высота первой
строки может стать отрицательной при временно малой области и safe area.
Мини-доска: (side − 4 × max(0.8, side × 0.014)) / 3 отрицательно при side <3.2.
Нужны конечные безопасные размеры и отказ от рисования недопустимого макета,
не изменение принятой нормальной геометрии.

FontManager.updateAvailableFonts всегда присваивает @Published массиву
те же 11 имён. Вызов из SettingsManager.init может совпадать с обновлением
SwiftUI. Каталог не зависит от языка по текущей шрифтовой политике.

MusicManager выполняет setCategory/setActive и создание AVAudioPlayer
синхронно из обработчиков главного экрана. Они могут задерживать main thread.
Перенос в последовательный фоновый контекст должен сохранить согласованность
play/stop, флаг настройки и обработку ошибок, без sync-моста, блокирующего UI.

## Ограничения

Сохранить дизайн, двухсекундную заставку, типографику, механику и данные.
Не менять PNG ради предполагаемой оптимизации без измерений.
Проверить крайние размеры, повторную настройку шрифтов, порядок аудиокоманд
и Release-компиляцию. Время холодного запуска/отсутствие runtime warnings
на iPhone нельзя подтверждать лишь статической проверкой или сборкой.
Финальное устройство и Xcode Runtime Issues проверяет владелец.

## Реализация

- DifficultyPickerGeometry.swift: проверка конечности/положительности
  viewport до построения макета, ограничение вертикальных интервалов,
  неотрицательная сторона клетки мини-доски. DifficultyPickerView использует
  эти расчёты; утверждённые обычные координаты, фон и типографика сохранены.
- FontManager.availableFonts — неизменяемый let из 11 имён. Убраны вызовы
  updateAvailableFonts из SettingsManager.init и смены языка SettingsView;
  список по действующей политике не зависит от RU/EN. Пользовательский
  selectedFont и его сохранение не изменялись.
- MusicOperationExecutor.swift: последовательная фоновая очередь,
  результат асинхронно на главную очередь, без sync/wait на UI.
  MusicManager выполняет setCategory/setActive, создание/prepare/play/stop
  AVAudioPlayer в этой очереди. Синхронный audio API сохранён ради iOS17.6;
  установленный SDK помечает новый async activate как iOS27+.
- StartView: настройка звука меняется после результата операции, повторный
  тап блокируется на время запроса; запуск после заставки не дублируется
  при уже ожидающем запросе. Ошибка запуска оставляет звук выключенным.

## Программные проверки

Изолированный Swift harness: zero/tiny/NaN/Inf и нормальная геометрия,
последовательность аудиокоманд вне main, callbacks на main — PASS.
Это проверка диспетчера и вычислений, не реальное AVAudioSession на iPhone.
Diff без ошибок. После исправления компиляционной ошибки вывода типа
результата generic-диспетчера финальная generic iOS Release-сборка успешна.
Новые исходники включены в синхронизированную группу проекта.

Время холодного запуска и Runtime Issues после правки НЕ измерены.
Обязательная личная приёмка: полностью завершить приложение и открыть снова,
проверить отсутствие подвисания при включении/выключении музыки, переходы
к выбору сложности/назад и смену RU/EN. Не удалять приложение/сохранения.
Заданная ранее заставка 2с и растворение 0,55с сознательно сохранены;
это ожидаемая длительность заставки, а не измерение быстродействия.

Этап затрагивает MusicManager, новый MusicOperationExecutor,
DifficultyPickerView, новый DifficultyPickerGeometry, FontManager,
SettingsManager, SettingsView и StartView. Ассеты, механика, данные,
шрифтовая политика и номер версии не менялись.
