# Инструкции для всех агентов проекта

Полные инструкции: `Sudoky/Проектная документация/AGENTS.md`.
Перед существенными изменениями также прочитать
`Sudoky/Проектная документация/Контекст проекта.md`.
Для редизайна — `Sudoky/Проектная документация/Редизайн.md`.

Правило владельца от 10 октября 2026: всем агентам, включая руководителя,
запрещено запускать/использовать симуляторы, устанавливать в них приложение,
просматривать интерфейс, снимать скриншоты или проводить UI-обходы.
Разрешена компиляция без запуска приложения (в том числе для generic
iOS Simulator SDK). Выполнить задачу, провести соразмерные программные
проверки и успешную сборку, кратко отчитаться и ждать личной приёмки владельца.
Не повторять успешную сборку и проверки другим агентом без причины.
Тесты, требующие симулятора, автоматически не запускать. Исключение — только
новое прямое разрешение владельца на конкретную проверку.
