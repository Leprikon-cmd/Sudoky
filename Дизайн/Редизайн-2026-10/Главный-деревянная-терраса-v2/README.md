## Дизайн

Фон — более приглушённые серо-сепийные горы, озеро, осенняя ветка,
палевая бумага, мягкое солнце. Деревянный настил начинается примерно
y=.545 и идёт до самого низа. На нём нет дерева, горшка, кнопок/надписей.
Зона контакта горшка в центре ориентировочно x=.5,y=.59: достаточно
ниже заднего края настила, а не поверх линии горизонта.
Нижняя зона под4 кнопки — та же деревянная поверхность, не пустая бумага.

Все4 кнопки без текста, с тёмной кистевой окружностью/значком слева,
пустой бумагой для живой локализации и слабым бамбуковым орнаментом справа.
Значки: гора/дорога, росток, три ступени, кисть/чернильница.

## Следующая интеграция — только после утверждения артов

- Существующие10 стадий дерева, пустой сад, музыка/настройки,4 постоянных
  слота и действия сохранить. Менять только главный, не механику/данные.
- Фон масштабируется пропорционально, положение ножек горшка — по той же
  карте изображения. Не использовать прежний контакт .523 от каменного фона:
  здесь другая поверхность, требуются новые метрики.
- Тень — отдельный слой непосредственно ПОД горшком, не под кроной и не
  .shadow на всём дереве. Нормализовать её прозрачные поля по таблице;
  рисунок находится существенно ниже центра полного файла.
  В видимом виде ширина около90–100% ширины горшка, высота около6–8%
  его ширины; тёмное ядро у ножек. Начальный opacity≈.55–.7 с учётом
  собственной alpha PNG (максимум246). На пустом саде тень не показывать.
  Предыдущая программная тень существует, но визуально не читается на
  снимке владельца — не считать её выполненной художественной задачей.
- Кнопки широкие/компактные,4 слота ближе к низу, не изменяются при hasSave.
  Каждый рисунок нормализовать отдельно, не предполагать одинаковые bbox.
  Если нужен runtime horizontal slice, защищать левый значок И правый
  бамбуковый орнамент; тянуть только пустую середину, не обводки/листья.
  Не сплющивать весь PNG ради54 pt. Названия RU/EN рисуются Text/FontManager.
- Одна generic Debug-компиляция после подключения, без симуляторов/запуска.
  Фактический контакт горшка и тени принимает только владелец.

## Выдача RD-01G — пробная интеграция

Владелец разрешил подключение этого набора. Разработчику выдан ограниченный
этап: StartView +6 новых imageset (фон,4 кнопки,тень). Исходники скопировать
побайтово, старые assets сохранить; pbx/xcstrings/механика/другие экраны защищены.

Композиция: фон852×1847 пропорционально на полный viewport, не наследовать
увеличение1.08 каменного варианта без причины. Контакт горшка по общей
геометрии фона x=.5,y≈.59; взрослый бонсай крупный, ориентир рамки
min(.46H,W−16), с учётом10 стадий и прежнего пустого сада. Границы горшка
и тени согласованы; PNG тени .55–.7 непосредственно у ножек, с сохранением
мягких краёв (не обрезать всю низкую alpha по bbox32).

Кнопки примерно90% ширины телефона/максимум460 pt iPad, высота54–58 pt,
интервалы6–8 pt и нижний отступ10 pt от Safe Area. На малой высоте допускается
сокращение до44 pt/интервалов, но не скролл. Все4 слота постоянны.
Новые метрики каждой кнопки отдельны. Защитить весь левый круг и правый
орнамент; прежние caps400/120 от старых PNG **не переносить автоматически**.
Текст20–22 pt через существующие loc/textStyle, не наезжает на орнамент.

Разработчик проверяет ресурсы/parse/diff и короткую матрицу геометрии;
известную sandbox-сборку не повторяет. Руководитель выполняет одну generic
Debug-компиляцию без запуска. Симуляторы запрещены. После отчёта остановка
для личной приёмки владельца; другой этап не разрешён.
