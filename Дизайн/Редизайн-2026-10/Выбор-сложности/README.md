# RD-02B — интерактивная композиция пяти сложностей

Утверждённый владельцем материал, 11 октября 2026.
`difficulty_path_background.png` — первый файл вложения, без текста, 1024×1536.
`difficulty_path_reference.png` — второй файл, ориентир живых подписей.
Копии побайтовые, рисунок не редактировать и не заменять новой генерацией.
В Assets подключать только фон без текста, под именем `difficulty_path_background`.
Референс с надписями не показывать в приложении.

## Геометрия

Один внутренний холст 1024×1536. Для доступного прямоугольника контейнера
W×H вычислить s = min(W/1024, H/1536), размер изображения 1024s×1536s
и центрированный origin. Изображение не растягивать и не обрезать.
Поля вне холста — спокойная бумажная заливка, не случайный другой рисунок.
Safe area/system bars не должны закрывать стрелку или подписи.
На iPad холст вписывается той же формулой, без отдельной перестановки ступеней.

Точки/прямоугольники ниже — доли ширины/высоты ИЗОБРАЖЕНИЯ, не экрана.
Преобразование: x_screen = origin.x + x × imageWidth, аналогично y;
ширина/высота = относительная величина × imageWidth/imageHeight.
Текст/кнопки внутри одного image-sized ZStack используют те же величины.

Ступени уже существенно выше 44 pt на целевых размерах iPhone.
