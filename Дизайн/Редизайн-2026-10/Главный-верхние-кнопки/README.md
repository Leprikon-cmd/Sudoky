# Верхние кнопки главного — RD-01E

Новые референсы владельца от 11 октября 2026: свиток в кистевой окружности
и свирель с нотой. Встроенный imagegen: прозрачное извлечение, затем OFF
редактированием ON с удалением ноты. Промпты полностью в «Промпты.md».
Оригиналы сохранены отдельно от Assets; старые PNG не удалять.

Все три PNG 1254×1254 RGBA, alpha 0…255. Границы по alpha ≥32, правый/
нижний предел исключён; картинки просмотрены, прозрачность проверена.

| Файл | Видимые границы x / y |
| --- | --- |
| home_settings_scroll_v2.png | 81…1178 / 101…1140 |
| home_music_flute_on_v2.png | 77…1167 / 96…1162 |
| home_music_flute_off_v2.png | 76…1169 / 94…1163 |

ON/OFF одного размера, OFF без ноты; без волн и перечёркивания. При генерации
есть небольшое отличие краевых кистевых пикселей (1–2 px), поэтому не
нормализовать каждую картинку по отдельности. Для обоих состояний применять
общие метрики от ON: x77, y96, width1090, height1066. Масштаб=52/1090,
центрирование по bbox ON, одна область нажатия 58×58 pt, без индивидуального
clipping/crop PNG. Тогда состояние не меняет геометрию SwiftUI.

Настройки отдельно: x81,y101,width1097,height1039; масштаб=52/1097.
PNG должен сохранять пропорции, видимый круг около 52 pt. Внутри кистевой
окружности фон прозрачный; бумага только внутри нарисованного свитка.

Слева — музыка, справа — настройки, прежние действия/accessibility RU/EN.
Схема отображения не заменяет проверку реального звука. Агенты не запускали
приложение/симулятор и не прослушивали музыку, ручная приёмка — у владельца.
