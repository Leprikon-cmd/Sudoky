## Подключение

- Имена ресурсов: home_button_about, music_flute_on, music_flute_off.
- Кнопку «О проекте» размещать после «Уровни познания»: та же видимая ширина,
  пропорциональная картинка, рисунок слева, текст после рисунка по общей линии.
- Кнопка звука в верхнем левом углу; настройки справа. Свирель без бумажного
  фона, аналогично отдельному изображению свитка настроек. Область ≥44 pt.
- ON/OFF используют ОДИН общий холст/масштаб/смещение. Можно оставить исходные
  квадратные файлы; при нормализации обрезать обе копии по одному объединённому
  прямоугольнику (195, 148)–(1143, 1088), а не по отдельным bbox. Иначе при
  переключении инструмент изменит размер/положение. Изображения scaledToFit.
- OFF отличается отсутствием волн, не перечёркиванием/красным крестом и
  не только уменьшенной прозрачностью. Состояние также обозначить VoiceOver.
- Использовать прежний settings.soundEnabled и существующие методы музыки;
  новый ключ хранения не вводить. Убрать прежние входы из SettingsView.
- Старые ресурсы/исходники не удалять. Промпты рядом в Промпты.md.

Приёмка интерфейса только владельцем после успешной компиляции; агенты
симуляторы, UI-тесты и скриншоты приложения не используют.
