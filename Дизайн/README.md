# Рабочие исходники дизайна

## Восстановление по просьбе владельца — 13 октября 2026

Все изображения и сопутствующие документы, перемещённые при ревизии,
возвращены на исходные места в Дизайн. Старые варианты, референсы и
история генераций сохраняются здесь по прямому решению владельца.
Не считать отсутствие ссылки из кода основанием для удаления этих материалов.
Сортированные копии и резервные копии в архиве/корзине пока сохранены.
Описание сортировки ниже относится к дополнительно созданной структуре,
а не к разрешению вновь убирать оригиналы.

Ревизия: 13 октября 2026. Изображения восстановлены без изменения байтов.
Ресурсы приложения подключаются из Sudoky/Assets.xcassets, не из этой папки.

- Сад/Дуб — Oak_Stage_01…10.
- Сад/Бук — Beech_Stage_01…10.
- Сад/Клён — Maple_Stage_01…10.
- Сад/Можжевельник — Juniper_Stage_01…10.
- Сад/Яблоня — Apple_Stage_01…09; стадия 10 ожидается от владельца.
- Сад/Тени — отдельная контактная тень горшка.
- Кнопки — главный экран, музыка, настройки, сад и общая навигация.
- Фоны — пять бумажных фонов, высокий путь сложности, деревянная терраса.
- Иконки — жизни и существующие показатели статистики.
- Книга-и-объявления — книжный лист и пергамент завершения.
- [Иконка-приложения-v2](Иконка-приложения-v2/Задание.md) — незавершённое
  задание; новой PNG нет, действующий AppIcon остаётся прежним.

Существующие PNG не перерисовывать и не нормализовать повторно.
Часть исходников имеет прозрачные поля, поэтому имя/размер файла не
определяет видимый размер кнопки. Подключённые копии могут иметь другие
границы после прежнего crop; оригиналы здесь сохраняют исходный рисунок.
stats_*_v1 соответствуют подключённым stats_* без суффикса,
settings_ink_language_v1 — settings_ink_language.
