Метрики сняты с исходников. Сохранять единый полный квадратный холст:
ранние стадии не увеличивать до размеров взрослой кроны. Общий ориентир
нижнего контакта горшка y=948/1024, отличающийся от дуба (967/1024).
Разница нижних краёв бука между стадиями — не более двух пикселей;
не вводить отдельный динамический crop каждой стадии.

Импортировать отдельными beech_stage_01 … beech_stage_10.imageset,
PNG побайтово, исходники и дуб не заменять. На главной применить якорь
бука к существующему контакту террасы и тени; не менять фон/кнопки.
Подключение, правила и границы этапа — «Проектная документация/Механика сада.md»,
секция GARDEN-02. Визуальную приёмку выполняет только владелец.
