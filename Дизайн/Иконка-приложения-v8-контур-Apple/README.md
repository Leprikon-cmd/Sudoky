# Рамка по официальному контуру Apple

14 октября 2026. Лицензия Apple Design Resources принята с прямого разрешения
владельца. Официальный источник:
https://devimages-cdn.apple.com/design/resources/download/iOS-27-Icon-Templates-Photoshop-Illustrator.dmg

## Геометрия

Контур извлечён из слоя App Icon Shape официального Illustrator-шаблона,
PDF-совместимый App Icon Template.ai. Сохранены все 44 команды вектора,
включая кубические кривые; координаты переведены в систему 1024×1024.
Произвольный cornerRadius, приближение superellipse и генератор углов
не использовались. contour.json — исходные координаты после перевода осей.

Рамка строится CoreGraphics-stroke шириной 64 px на границе Apple и затем
обрезается этой маской: видимая часть внутрь 32 px. Это параллельный контур,
а не уменьшенная копия формы с переменной толщиной. Текстура эбена взята
из утверждённого изображения, рисунок/цифры/перламутр не генерировались заново.
Проверены 4444 точки границы и смещения внутрь 2/16/30 px:
обрывов/выходов проверяемого участка рамки нет.

## Файлы и подключение

- app-icon-circle-apple.png — основной файл 1024×1024, RGB без прозрачности,
  побайтово подключён в AppIcon.appiconset/icon1.png.
- app-icon-plain-apple.png — второй сохранённый вариант, без обводки.
- preview-*-apple.png — статические просмотры с официальной маской;
  здесь углы прозрачные, это НЕ файлы для AppIcon.
- preview-*-120px.png и preview-*-180px.png — уменьшенные просмотры.
- apple-mask.png — маска для проверки, не ассет приложения.
- app-icon-before-v8.png — предыдущая иконка, сохранена.
- Шаблон/ — официальный AI, лицензия, извлечённые координаты и извлечение.
- render.swift — воспроизводимая сборка растров CoreGraphics; вывод в Rebuild/.
  Исходные художественные изображения остаются в v7-чернила.

Угловое содержимое квадратного файла вне маски не отображается iOS.
Альфа предусмотрена только у статического просмотра, не у AppIcon.
Просмотр официальной маски выполнен как работа с ассетом, не через симулятор.
Фактический вид на устройстве/эффекты конкретной iOS принимает владелец.
Точная геометрия соответствует полученному шаблону iOS 27; фактическая
маска другой версии iOS этим не проверялась.
Код приложения, версия, навигация и механика не менялись.
