# Судоку. Путь мудреца

Спокойная офлайн-игра для iPhone и iPad: пять сложностей Sudoku, заметки,
жизни, сохранение партии, статистика, музыка и сад бонсай. Русский и английский.
Без рекламы и аналитики, платёжных кнопок и заглушек. На первом листе книги
«О проекте» — информационные ссылки на сайт проекта и сообщество.

## Работа с проектом

Открыть Sudoky.xcodeproj в Xcode, схема Sudoky. В текущем target минимальная
система — 17.6 (значение не изменялось при последних визуальных правках).
Агенты не запускают симуляторы и приложение; визуальную приёмку проводит
владелец. После изменения кода — соразмерная программная проверка и компиляция
без запуска. Для документации сборка не требуется.
Исключения требуют прямого разрешения владельца; текущий ограниченный
проход TYPO-BOOK-01 описан в проектных инструкциях.

SwiftUI / MVVM. Код — Sudoky/, тесты — SudokyTests/ и SudokyUITests/.
Локализация — Localizable.xcstrings, шрифты — FontManager.
Интерфейс — Old Standard TT, обе книги — Cormorant Garamond. Пользовательский
шрифт применяется только к цифрам и заметкам игрового поля; предпросмотр 9×9
в настройках использует те же компоненты, не текущую партию.
Подключённые ресурсы — Assets.xcassets, исходные PNG — Дизайн/.
docs/ — сайт проекта, не архив внутренней документации.

## Незавершённое

- Отдельная архивируемая тестовая конфигурация с жуком ещё не настроена.
- Покупки поддержки исключены из текущего релиза; не возвращать старые заглушки.
- Визуальная приёмка последних локальных этапов выполняется владельцем.
- Четыре скриншота TYPO-BOOK-01 не получены: в выбранном окружении отсутствует
  приложение Simulator.app; успешная компиляция не заменяет UI-проверку.
