# Судоку. Путь мудреца — Контекст проекта

## О проекте

**Судоку. Путь мудреца** — бесплатное приложение для iPhone и iPad.

Главная идея проекта — создать красивое, спокойное и полностью бесплатное Sudoku без рекламы, встроенных покупок и навязчивой монетизации.

Проект разрабатывается как подарок игрокам и как демонстрация качественной разработки.

# Основные менеджеры

## FontManager

Отвечает за

* выбор пользовательского шрифта
* централизованную выдачу шрифтов
* смещение отдельных шрифтов
* автоматическую фильтрацию шрифтов по языку

Все тексты приложения используют

```swift
.textStyle(...)
```

Напрямую `.font(...)` практически нигде использовать не рекомендуется.

---

## SettingsManager

Хранит пользовательские настройки

* язык
* звук
* внутренний цвет текста (без пользовательского выбора с TD-01)
* выбранный шрифт
* таймер
* настройки интерфейса

Все значения сохраняются через AppStorage.

---

## MusicManager

Отвечает за воспроизведение фоновой музыки.

Особенности:

* музыка запускается один раз;
* при переходах между экранами не начинается сначала;
* управляется через Settings.

---

## LanguageManager

Отвечает за локализацию приложения.

Поддерживаются

* русский
* английский

Все строки локализуются через

```swift
loc("...")
```

# Генератор Sudoku

Используется собственный генератор.

Алгоритм:

1. создаётся полностью заполненная доска;
2. затем удаляются клетки;
3. после каждого удаления запускается решатель;
4. если решений становится больше одного — удаление отменяется.

Это гарантирует единственное решение каждой головоломки.

---

# Решатель

Используется Backtracking.

Основные задачи:

* проверка уникальности
* проверка генератора
* возможное развитие интеллектуального анализа сложности.

# Принятые решения

Во время разработки было принято несколько важных архитектурных решений.

* Централизация шрифтов через FontManager.
* Централизация цвета текста через SettingsManager.
* Полный отказ от рекламы.
* Использование локального хранения данных.
* Генерация только головоломок с единственным решением.
* Автоматическая фильтрация шрифтов по поддерживаемому языку.
* Максимальное использование собственных компонентов SwiftUI.
* С 11 октября 2026 игра всегда в светлом режиме независимо от темы устройства
  (RD-LIGHT: системная политика Light и корневой preferredColorScheme).

## 

**"Как работать с этим проектом"**.

- Перед любым рефакторингом сначала понять существующую архитектуру.
- Не дублировать логику, если её можно централизовать.
- Новые настройки всегда хранить через `SettingsManager`.
- Новый текст всегда локализовывать сразу на русском и английском.
- Новый UI-компонент сначала рассматривать как переиспользуемый.
- Всегда комментировать нетривиальный код.
- Перед изменением игровой логики проверять, не ломает ли она сохранения и генератор.
- Правило владельца от 10 октября 2026 для всех агентов, включая руководителя:
  не запускать и не использовать симуляторы. Выполнить задачу, программные
  проверки и компиляцию без запуска приложения, отчитаться и ждать личной
  проверки/утверждения владельца. Не дублировать успешные проверки без причины.
  Тесты с запуском симулятора требуют отдельного прямого разрешения владельца.
