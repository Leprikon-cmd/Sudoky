# RD-01E — верхние кнопки главного и исправление музыки

Прямое задание владельца 11 октября 2026. Только этот этап, без продолжения
других RD. Главный разработчик реализует, руководитель готовит PNG/задачу.

## Что сделать

1. Слева на главном свирель в кистевом круге по новому референсу.
   Музыка включена — есть нота, выключена — только та же свирель/круг.
   Не перечёркивать, не добавлять волны. Справа — свиток в таком же круге.
   Оба видимых круга 52 pt, области нажатия не меньше 58×58 pt.
   У on/off одинаковые canvas, масштаб, координаты; не нормализовать каждый
   по своему bbox. Меняется только нота, свирель не прыгает/не вращается.
2. Убрать отображение текущей ступени и линейной полосы с главного.
   Удалить только ставшие ненужными локальные UI-метрики/формулу отображения;
   PlayerProgressManager, XP/ступени/ключи хранения и начисления не менять.
   Дуб остаётся кнопкой сада над нижними четырьмя действиями, порядок/
   artwork/текст/условие hasSave и маршруты прежние; звук/настройки сверху.
3. Исправить включение музыки узкой правкой MusicManager/StartView.
   Файл Aurnis_Luthael.m4a читается, AAC stereo 44.1 kHz ~364.8 s, уже есть
   в собранном .app — менять файл, имя/автора, громкость 0.5, loop или
   ресурсы проекта не нужно. Проблема вероятно связана с default аудиосессией:
   AVAudioSession не настроен, беззвучный режим iPhone заглушает default audio.
   Это подтверждённый риск кода, фактический триггер на устройстве ещё не проверен.
4. Когда владелец явно включает музыку внутри приложения, настроить
   AVAudioSession .playback / .default / .mixWithOthers и активировать.
   Проверять результат AVAudioPlayer.play(), обрабатывать ошибки настройки/
   активации/запуска, не сообщать успешный старт при false. По выключению
   остановить плеер и деактивировать с .notifyOthersOnDeactivation.
   Не включать Background Modes и не менять Info.plist/Capabilities;
   не строить новую систему фонового воспроизведения/прерываний.
   Использовать прежний soundEnabled в SettingsManager, не musicEnabled
   и не новый ключ. Успешные переходы между экранами не перезапускают музыку.
   Существующие RU/EN accessibility подписи/состояния сохранить.

Документация Apple: [Audio Session Default Behavior](https://developer.apple.com/library/archive/documentation/Audio/Conceptual/AudioSessionProgrammingGuide/AudioSessionBasics/AudioSessionBasics.html).
Именно влияние silent mode объяснено источником; это не доказательство
звука на конкретном устройстве владельца.

## Проверка

Узкие проверки ресурсов/обработчиков/аудиосессии и diff; по возможности
беззвучная программная проверка ветвей успеха/ошибки без симулятора.
Сборка один раз руководителем generic Debug без запуска, известный sandbox
macro-блокер не повторять. Никаких симуляторов, UI/скриншотов или автоматического
прослушивания: владелец лично проверяет звук с silent on/off, многократный
toggle, отсутствие перезапуска при переходе в настройки/сад/игру и обратно,
нотную пиктограмму, свиток и отсутствие ступени/полосы на главном.

Статус: read-only аудит завершён; три финальных PNG готовы, метрики и
