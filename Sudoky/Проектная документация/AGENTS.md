# AGENTS.md

## Проект

«Судоку. Путь мудреца» — бесплатное офлайн-приложение Sudoku
для iPhone и iPad без рекламы, аналитики и встроенных покупок.

Фактический корень Git и Xcode-проекта: `Sudoky/`.
Основной проект: `Sudoky.xcodeproj`.

## Главная документация

Перед существенными изменениями прочитать:

`Sudoky/Проектная документация/Контекст проекта.md`

Если код и документация расходятся, сначала сообщить пользователю
о расхождении, а не исправлять его по предположению.

## Принципы работы

- Сначала изучить фактическое состояние связанных файлов.
- Делать небольшие и обратимые изменения.
- Не переписывать работающие части без необходимости.
- Не менять игровую механику за рамками поставленной задачи.
- Не менять сохранения и формат данных без отдельного согласования.
- Сохранять все посторонние локальные изменения пользователя.
- Не выполнять commit, push и публикацию без прямого разрешения.
- Не удалять файлы без подтверждения.

## Архитектура

- Интерфейс: SwiftUI.
- Основной подход: MVVM.
- Настройки должны проходить через `SettingsManager`.
- Шрифты должны выдаваться через `FontManager`.
- Локализация должна использовать существующий механизм `loc(...)`.
- Не дублировать функции существующих менеджеров.

## Локализация

Любой новый пользовательский текст необходимо локализовать.
Минимально поддерживать русский и английский языки.
При изменении существующего текста проверить остальные локализации.

## Проверка изменений

После изменения исходников:

1. Проверить компиляцию проекта.
2. Запустить связанные unit-тесты.
3. Для интерфейсных изменений проверить соответствующий экран.
4. Отдельно сообщить, что действительно проверено, а что проверить не удалось.

Отсутствие или неисправность симулятора не считать доказательством
ошибки в исходном коде.

## Границы задачи

Не расширять задачу самостоятельным рефакторингом.
Обнаруженные проблемы вне поставленной задачи перечислить отдельно.
